RESULT: Fixed cross-industry sibling links in link-graph.ts and service page template - audit passes with zero broken /services/ hrefs on non-blog pages

## Root Cause Fix Summary

The bug had two failure modes:
1. **link-graph.ts** was generating sibling service-page links using ALL categories from `serviceCategories` without filtering by `industrySlug` or checking if the service page actually existed (≥3 businesses threshold)
2. **Service page template** (`src/pages/services/[industrySlug]/[categorySlug]/[citySlug].astro`) was generating "Related Categories" links without filtering by `industrySlug`

Both issues fixed by:
- Importing and using `matchBusinesses()` to check if a service page exists (≥3 businesses threshold)
- Filtering categories by `industrySlug` before generating links
- Modified `hasServicePage()` helper to use actual threshold logic from `getStaticPaths`
